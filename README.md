# Space Portfolio - Astronomy Project Showcase

## Project Description
A modern portfolio showcasing astronomy projects and space exploration visualizations.

## Prerequisites
- Node.js 18+
- npm/yarn
- Git

## Local Setup
```bash
git clone https://github.com/jostoz/Space-Portolio.git
cd Space-Portolio
npm install
npm run dev
```

## Available Scripts
- `dev`: Start development server
- `build`: Create production build
- `start`: Run production server
- `lint`: Run code linter

## Project Structure
```
Space-Portolio/
├── app/          # Application pages
├── components/   # Reusable components
├── public/       # Static assets
└── utils/        # Utility functions
```

## Technologies
- Next.js
- React
- TypeScript
- Tailwind CSS
- Three.js (for 3D space visualizations)

## Features
- 🚀 Interactive space visualizations
- 🌌 Astronomy project showcases
- 📡 Real-time data integrations
- 📱 Responsive design
